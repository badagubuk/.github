# 🐢 바다거북스프 개발팀

**AI와 기술로 새로운 게임 경험을 만듭니다.**

바다거북스프 개발팀은 기술을 활용해 사람들이 함께 즐길 수 있는 새로운 경험을 만들어 나가는 개발팀입니다.

단순히 기능을 구현하는 것을 넘어, 사용자가 서비스를 통해 더 즐겁고 새로운 경험을 할 수 있도록 고민합니다.

## 💡 Our Principles

* **User Experience** — 사용자가 직관적이고 편리하게 이용할 수 있는 서비스를 만듭니다.
* **Continuous Improvement** — 사용자 피드백을 바탕으로 끊임없이 개선합니다.
* **Reliability** — 안정적이고 지속 가능한 서비스 운영을 지향합니다.
* **Experimentation** — 새로운 기술과 아이디어를 적극적으로 실험합니다.
